# GeoPulse – Hyper-Local Retail Mobility Analytics

## Project Overview
GeoPulse analyzes GPS/mobility and retail location data to identify
movement patterns, nearby stores, and high-activity areas.

## Technologies
- Python
- PySpark
- Apache Sedona
- Snowflake
- SQL
- Pandas

## Current Progress
- Dataset selected and reviewed
- Dataset columns and data types analyzed
- Python environment configured
- Java 17 installed
- PySpark configured
- Apache Sedona setup started
- Snowflake environment configured
- Spatial analysis implementation in progress

## Spatial Analysis
Using PySpark and Apache Sedona to:
- Convert latitude/longitude into spatial points
- Perform spatial transformations
- Associate GPS points with retail/store locations
- Analyze device movement and activity areas
